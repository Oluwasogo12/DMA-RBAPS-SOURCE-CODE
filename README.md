# Dynamic Mastery Assessment (DMA-RBAPS)

A Rule-Based Adaptive Personalized UTME & SSCE Practice System developed to improve examination preparation through mastery learning, adaptive question selection, and real-time performance analytics.

Unlike traditional CBT platforms that present questions in a fixed order, DMA-RBAPS continuously adapts to each student's strengths and weaknesses, ensuring practice sessions focus on areas requiring improvement.

# 🧠 Adaptive Learning Engine

The adaptive engine personalizes every student's learning experience using five rule-based decision mechanisms.

### Rule 1 — Remedial Focus

Prioritizes topics with the lowest mastery score.

### Rule 2 — Progressive Challenge

Advances students to more difficult questions after consistent correct answers.

### Rule 3 — Mastery Reinforcement

Continues practice on weaker topics until mastery is achieved.

### Rule 4 — Prerequisite Validation

Ensures prerequisite topics are mastered before introducing advanced concepts.

### Rule 5 — Instant Feedback

Provides immediate corrective feedback after every question.
